# 🧩 逻辑工坊 —— 编程逻辑训练器

> **别急着告诉电脑怎么做，先想清楚它什么时候该停。**

一个要求学习者**先定义「什么时候结束」**，再通过可运行的逻辑零件搭出解决过程，并实时观察变量、条件、循环和输出如何一步步变化，最后把这套思维自动映射成真实 Python 代码的编程逻辑训练器。

整个软件就一个文件：`index.html`，双击即玩，无需安装任何东西。

---

## 🎯 它解决什么问题

新手学编程最大的坑不是语法，而是**逻辑**：不知道从哪下手、循环写着写着就死循环、变量在脑子里绕成一团浆糊。

逻辑工坊把编程拆成一件件「实体玩具零件」，像拼积木一样拼出逻辑——但有一条铁律：

**动手之前，先写出口（Stop Rule First）。**

只要有循环，必须先回答「这个循环什么时候该停」，系统才会让你继续拼。这个顺序练熟了，写真实代码时就不会再有停不下来的死循环。

## 🗺️ 整体流程（对应产品底层总图）

```
【任务目标 Goal】→ 我到底想让电脑干嘛
        ↓
【先写出口 Stop Rule】（有循环时，第一件事）
        ↓
【输入 Data / 初始状态 State】
        ↓
【逻辑零件 Logic Pack】
   顺序 · 条件 · while · for · 筛选 · 查找 · 计数 · 累加
        ↓
【组装具体条件 / 动作】→ 逻辑树
        ↓
   ┌────────┼────────┐
Python生成   执行引擎   轨迹引擎
Python代码   当前状态   每一步记录
   └────────┼────────┘
        ↓
【判定引擎】
 结构完整 · 能运行 · 能终止 · 逻辑正确 · 答案正确
        ↓
【学习反馈】人话 → 逻辑 → Python
```

## 🧰 九种逻辑零件

| 分类 | 零件 | 作用 |
|------|------|------|
| 顺序零件 | 📦 赋值 | 把一个值放进变量 |
| 顺序零件 | 📣 输出 | 把结果说出来 |
| 条件零件 | 🔀 条件 | 满足条件才做（可带「否则」） |
| 循环零件 | 🔁 for 循环 | 把列表里每一个都过一遍 |
| 循环零件 | ♻️ while 循环 | 一直做，直到出口（**必须先写出口**） |
| 数据零件 | 🔭 筛选 | 从列表里挑出满足条件的 |
| 数据零件 | 🔍 查找 | 找到第一个满足条件的 |
| 数据零件 | 🔢 计数 | 数一数有几个满足条件 |
| 数据零件 | 🧮 累加 | 把列表里的数加起来 |

## ⚖️ 五维判定引擎

每次运行，从五个维度打星（每关最多 5 星）：

1. **🧱 结构完整** —— 每个零件的参数都填齐了，没有空壳零件
2. **⚙️ 能运行** —— 从头跑到尾没有报错
3. **🛑 能终止** —— 所有循环都正常走到了出口，没有死循环（超过 3000 步自动报警）
4. **🧠 逻辑正确** —— 用上了该用的零件，产出了有意义的结果
5. **🎯 答案正确** —— 输出和预期一致（初级关卡开放式判定：能跑通就算赢）

## 🎮 玩法

1. **闯关模式**：9 个关卡由浅入深（顺序 → 条件 → 数据零件 → for → while → 综合挑战），其中第 8 关「倒数五秒」是灵魂关卡——强制先写出口。
2. **自由搭建**：自己写目标、自己定义数据（列表写成 `[1,2,3]`），随便拼，自动保存。
3. 按下 **▶ 运行**，右侧「执行现场」一步步回放：变量观察窗实时变值、输出控制台逐条冒出结果，装配区里**当前正在执行的零件会发光**。
4. 「轨迹」页记录每一步判断（条件成立不成立、循环检查了几次出口）。
5. 「Python」页把你拼的逻辑自动翻译成真实可运行的 Python 代码（变量名直接用中文，和你的逻辑一一对应），一键复制。
6. 「判定」页给出五维打星 + 人话反馈：人话 → 逻辑树 → Python。

## 🚀 怎么运行

- **最简单**：下载 `index.html`，双击用浏览器打开。
- **在线玩**：开启 GitHub Pages（仓库 Settings → Pages → 选择 main 分支），即可得到在线地址。

## 🛠️ 技术说明

- 零依赖，单文件（HTML + 原生 JavaScript），纯浏览器运行。
- 自带迷你执行引擎：表达式白名单校验，安全沙箱求值。
- 进度（经验值、星级）保存在浏览器本地存储（localStorage）。
