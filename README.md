# 🧩 逻辑工坊 v2 —— 编程逻辑训练器

> **别急着告诉电脑怎么做，先想清楚它什么时候该停。**

一个要求学习者**先定义「什么时候结束」**，再通过可运行的逻辑零件搭出解决过程，并实时观察变量、条件、循环和输出如何一步步变化，最后把这套思维自动映射成真实 Python 代码的编程逻辑训练器。

整个软件就一个文件：`index.html`，双击即玩，无需安装任何东西。

## 🆕 v2 版本：两个世界 + 小笨机器人

v2 按照「**三岁小孩标准**」彻底重做了新手引导——**永远不要求玩家使用一个系统还没教过他的概念**：

### 🐣 新手冒险（教程模式，16 关）

- **小笨机器人**贯穿全程：一台特别听话但一点脑筋都不动的机器，你写对它就跑得分毫不差，写错它就错得明明白白——用它建立「解释器的心理模型」。
- **每关只解锁一个新零件**：第 1 关整个屏幕只有「📣 说出来」一个零件，玩到哪、解锁到哪。
- **聚光灯式引导**：跟着小笨走时，屏幕变暗、目标发光，一步只做一件事。
- **三级提示**：第一次卡住 → 只讲目标；第二次 → 指出该点的零件；第三次 → 「🤝 帮我放好」直接帮你完成。**新手教程里求助，绝对不扣星。**
- **人话报错**：不说「结构不完整」，说「🤔 小笨还不知道要说什么」。
- **Python 渐进揭露**：前几关不提代码，每关结束后才给一个「偷看 Python」按钮——先做对，再知道它叫什么。
- **中文运算符先行**：界面写「大于或者等于」，Python 对照时才揭晓 `>=`。
- **逻辑包变成奖励**：亲手搭过 for + if + 计数之后，才解锁「🔢 数一数」零件——并且可以「🔍 拆开看看」它的内部。

### 🔧 自由工坊（完整工作台）

教程毕业后的完全体，v1 的全部能力都在这里：

- 全部 9 种逻辑零件自由拼装，可嵌套、可增删、可调序
- 自定义变量与列表数据（写成 `[120, 45, 200]`）
- 逐句追踪回放：变量观察窗实时变值、当前执行的零件发光
- Python 一键对照 + 复制
- 五维判定：结构完整 · 跑得通 · 停得下来 · 逻辑合理 · 达成目标
- 自动保存草稿，关掉浏览器也不丢

## 🎯 它解决什么问题

新手学编程最大的坑不是语法，而是**逻辑**：不知道从哪下手、循环写着写着就死循环、变量在脑子里绕成一团浆糊。

逻辑工坊把编程拆成一件件「实体玩具零件」，像拼积木一样拼出逻辑——但有一条铁律：

**动手之前，先写出口（Stop Rule First）。**

第 9 关「永远的 5」会让你亲眼看着一个出口到不了的循环念「5」八百次，然后亲手修好它。练过一次，写真实代码时就再也不会有停不下来的死循环。

## 🧰 九种逻辑零件

| 分类 | 零件 | 作用 |
|------|------|------|
| 基础动作 | 📣 说出来 | 让小笨说一句话（print） |
| 基础动作 | 📥 放进盒子 | 把一个值放进变量 |
| 判断 | 🔀 分岔路 | 条件成立走一边（可带「否则」） |
| 循环 | 🔄 一直做 | while——**必须先写出口** |
| 循环 | 🔁 逐个拿 | for——把名单挨个过一遍 |
| 数据包 | 🔍 挑出来 | 从列表里挑出满足条件的 |
| 数据包 | 🎯 找一个 | 找到第一个满足条件的（break） |
| 数据包 | 🔢 数一数 | 数一数有几个满足条件 |
| 数据包 | ➕ 加起来 | 把列表里的数加起来 |

## ⚖️ 五维判定引擎（自由工坊）

1. **🧱 结构完整** —— 每个零件的参数都填齐了，没有空壳零件
2. **🏃 跑得通** —— 从头跑到尾没有报错
3. **🛑 停得下来** —— 所有循环都正常走到了出口（超过 3000 步自动报警）
4. **🧠 逻辑合理** —— 用上了该用的零件，产出了有意义的结果
5. **🎯 达成目标** —— 写下任务目标，系统帮你验货

## 🚀 怎么运行

- **最简单**：下载 `index.html`，双击用浏览器打开。
- **在线玩**：开启 GitHub Pages（仓库 Settings → Pages → 选择 main 分支），即可得到在线地址。

## 🛠️ 技术说明

- 零依赖，单文件（HTML + 原生 JavaScript），纯浏览器运行。
- 自带迷你执行引擎：表达式白名单校验、危险词拦截、安全求值；「纯词当文字」兜底，中文变量名直接可用。
- 教程引擎独立成层：每一步都是数据（教什么 / 说什么 / 谁亮 / 允许做什么 / 成功条件 / 提示 / Python 揭示），改剧本不用改引擎。
- 进度（XP、关卡、自由工坊草稿）保存在浏览器本地存储（localStorage）。
